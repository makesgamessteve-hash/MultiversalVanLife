# Spec Delta

## ADDED Requirements

### Requirement: Commitments to real places
History's promises (residents, monuments, ruins, battlefields) SHALL target places of the plan (a capital, a faith's first city, the region of a war) instead of fixed land numbers.

#### Scenario: The founder's statue
- **WHEN** a faith's founder is promised a statue
- **THEN** it stands in the main square of the faith's first city
